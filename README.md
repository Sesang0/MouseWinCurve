# MouseWinCurve

macOS용 포인터 영역 제한·가속·DPI 감도 보정 앱. Apple Silicon / macOS 13 이상.

## 1.0.0 첫 화면

일반 설정과 DPI는 첫 화면에 한 열로 세로 배치하고, 리그오브레전드 설정은 별도 창에서 엽니다. 화면이 작으면 스크롤하여 하단의 적용 버튼을 사용하세요.

- **연결된 마우스**: HID에서 제공하는 이름만 표시합니다. 여러 대일 때 선택할 수 있습니다. 장치가 이름을 `USB Receiver`로 보고하면 그대로 표시하며 실제 모델명을 추정하지 않습니다.
- **포인터 제한 영역**: 현재 디스플레이 배율이 반영된 논리 해상도(pt). 화면 전체 크기는 테두리를 숨깁니다.
- **포인터 속도**: 11단계, 6/11=1배. 첨부 그래프 근사 가속 켜기/끄기.
- **DPI 설정**: 현재 DPI를 직접 입력하고 목표 DPI를 설정합니다. 장치 DPI 자동 조회·재조회 버튼·연결 방식·조회 오류 표시는 제거했습니다.
- **리그오브레전드 설정**: **설정 열기** 버튼으로 별도 창을 엽니다. 활성화하면 실제 게임이 맨 앞에 있을 때만 별도 목표 DPI와 0~100 이동 속도를 적용합니다.

시작 프로그램·단축키 안내·권한 설정·입력 모니터링 버튼은 하단의 한 영역에 모았습니다. 리그오브레전드 설정 열기 버튼은 맨 아래에 있습니다.

## 실행과 종료

`MouseWinCurve.app` 실행 시 첫 화면을 엽니다. Dock과 메뉴 막대에 앱이 표시되며, 창을 닫아도 프로세스와 이미 적용한 잠금은 유지됩니다. Dock 아이콘 또는 메뉴 막대의 **설정 창 열기**로 다시 열 수 있습니다. 실행 중 Dock에 남는 동작이며, 종료 후에도 고정하는 ‘Dock에 유지’ 설정은 변경하지 않습니다.

**Command + Esc**는 현재 설정으로 활성화하거나 비활성화합니다. 앱이 실행 중이면 다른 앱에서도 사용할 수 있습니다. 앱 종료는 **Command + Q** 또는 메뉴의 **종료**입니다. 앱 종료·화면 구성 변경·잠자기·사용자 전환 시 잠금을 해제합니다.

처음 사용하거나 권한이 변경된 경우 시스템 설정 → 개인정보 보호 및 보안에서 앱의 **손쉬운 사용**, **입력 모니터링**을 허용하고 재실행하세요. 내부 번들 ID는 기존 설정 유지용으로 `local.mouselockcurve.app`을 유지합니다.

## 시작 프로그램

첫 화면의 **로그인 시 자동 실행 켜기** 버튼으로 등록하고 **자동 실행 해제**로 해제합니다. macOS 승인이 필요하면 **로그인 항목 설정**을 누르세요. 앱을 사용할 위치에 둔 뒤 등록하세요. 자동 실행 등록은 기본적으로 켜지지 않습니다.

아이콘에는 흰 배경과 검은 커서에 은은한 그라데이션과 그림자를 적용했습니다.

## 적용 순서

1. 연결된 마우스와 제한 영역을 선택합니다.
2. DPI 보정을 원하면 제조사 앱 등에서 확인한 현재 DPI를 입력하고 원하는 목표 DPI(1–57,343 정수)를 설정합니다.
3. 리그오브레전드 설정을 사용할 경우 활성화 체크와 게임 목표 DPI·이동 속도를 설정합니다.
4. **활성화**을 누릅니다.

장치에서 읽는 것은 이름과 포인터 처리에 필요한 원시 이동 입력입니다. DPI 읽기 명령과 DPI 쓰기 명령은 보내지 않습니다. 마지막으로 움직인 마우스를 자동 선택하며 잠금 중 트랙패드 병용은 지원하지 않습니다.

## 배율과 한계

처리 순서: 원시 이동 → 목표/현재 DPI 비율 → 가속 곡선(선택 시) → 11단계 속도 × 게임 추가 속도(해당 시) → 화면 배율 변환 → 경계 제한.

11단계 배율: `1/32, 1/16, 1/4, 1/2, 3/4, 1, 1.5, 2, 2.5, 3, 3.5`. 첨부 그래프는 수동 추출 지점을 보간하며 Windows 내부 알고리즘의 완전한 복제는 아닙니다.

리그오브레전드 0~100은 앱 자체의 보정값입니다. `2^((값-50)/25)`로 0=0.25배, 50=1배, 100=4배입니다. 게임 내부 수치와 동일한 배율을 보장하지 않습니다. 게임 목표 DPI는 일반 목표 DPI를 대체합니다. 런처는 제외하고 `com.riotgames.LeagueofLegends.GameClient` / `LeagueofLegends` 실행 파일만 감지합니다.

센서 DPI, macOS 전역 감도, 게임 파일을 변경하지 않습니다. 실제 센서보다 높은 목표 DPI는 입력 정밀도를 추가하지 않습니다. 게임이 시스템 포인터 입력을 우회할 경우 적용이 다를 수 있습니다.

## 빌드와 테스트

Apple Command Line Tools 필요:

```sh
./build.sh
./test.sh
```

앱은 로컬 ad-hoc 서명이며 Developer ID 공증은 포함하지 않습니다. 검증 범위는 `VALIDATION.md`에 기록합니다. 소스 파일의 기존 디렉터리명은 앱 표시 이름과 무관합니다.

우측 최상단 상태 표시 옆의 활성화 버튼은 기존 청록색이며, 실행 중에는 더 진한 빨간색 비활성화 버튼으로 바뀝니다.

DPI 설정은 화살표로 접고 펼칩니다. 접은 상태에서도 기존 DPI 값은 유지되며, 마지막 펼침 상태를 기억합니다. 백그라운드 실행 안내 문구는 첫 화면에서 제거했습니다.

영역 제한 없는 다중 모니터 모드는 추가하지 않았습니다. 현재 입력 처리는 선택한 화면의 배율과 단일 사각형 경계에 의존하므로, 혼합 배율과 화면 사이 빈 공간을 다루는 별도 좌표 처리가 필요합니다.

게임 목표 DPI와 기타 설정도 화살표로 접고 펼칠 수 있습니다. 기타 설정에는 시작 프로그램, 단축키 안내, 권한 설정, 입력 모니터링 버튼이 포함됩니다. 접어도 설정 값은 유지됩니다.

DPI 설정·기타 설정·게임 목표 DPI는 화살표뿐 아니라 제목과 제목 오른쪽 빈 영역을 눌러도 접고 펼쳐집니다. 기존 화살표와 글꼴 디자인을 유지합니다.

아이콘은 흰 배경의 청회색 설계도 격자와 검은 커서로 구성됩니다.

마우스 목록에는 1부터 번호를 표시합니다. 입력 모니터링 권한이 있으면 마지막으로 움직인 마우스로 자동 전환합니다(활성화 전후 모두). DPI 입력은 실행 중 장치별로 보관하며 처음 사용하는 장치는 보정 없음으로 시작합니다. 장치 재연결로 식별자가 바뀌거나 앱을 재시작하면 DPI를 다시 입력해야 합니다. 리시버가 실제 모델명을 제공하지 않으면 USB Receiver 표시를 유지합니다.

리그오브레전드 마우스 이동 속도 오른쪽 숫자에 0~100 정수를 입력하고 Enter를 누르거나 입력란을 벗어나면 적용됩니다. 잘못된 입력은 이전 값으로 복원됩니다. 슬라이더와 입력란은 서로 동기화됩니다. 배포 버전은 1.0.0이며 내부 빌드 번호는 업데이트 구분을 위해 17을 사용합니다.
